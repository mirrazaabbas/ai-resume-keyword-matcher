# AI Resume Keyword Matcher

A lightweight Python tool that compares a resume with a job description, extracts important job keywords, calculates overlap, and highlights missing terms to review honestly before applying.

## Features

- Resume/job text tokenization
- Stopword filtering
- Keyword frequency ranking
- Match percentage
- Matched and missing keyword lists
- UTF-8/file validation
- CLI workflow
- Automated tests and CI

## Run

```bash
python app.py sample_resume.txt sample_job.txt
```

## Example use

Use the missing-keyword list as a review aid only. Add a keyword to a resume only when it truthfully reflects your skills or experience.
